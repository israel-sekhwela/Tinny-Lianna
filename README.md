# Tinny Lianna's Daycare

A responsive, single-page website for Tinny Lianna's Daycare in Bonaero Park, Kempton Park.

## Features

- Daycare information, opening hours, and location
- Registration information and an in-page Letter of Intent form preview
- Gallery sections for facilities, meals, events, and school information
- Responsive layout and image-preview modal

## Run locally

Open `index.html` in a browser. Keep the `css`, `js`, and `forms` folders alongside it.

## Images

The daycare photos and logo in `assets/images/` are intentionally excluded from Git and remain local. The gallery and logo will therefore only display on machines that have those assets. Add images only when they are approved for publication.

## Letter of Intent

The form in `forms/` lets a family express interest and share information so the daycare can consider availability and follow up about next steps. It is not final registration and does not guarantee or reserve a place.
